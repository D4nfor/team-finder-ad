# TeamFinder

Дипломный проект TeamFinder. Реализован вариант 2: навыки пользователей и фильтрация участников по навыкам.

## Возможности

- регистрация, вход, выход и смена пароля;
- профиль пользователя с контактами, аватаром, описанием и навыками;
- добавление и удаление навыков без перезагрузки страницы;
- автодополнение навыков;
- список участников с фильтрацией по навыкам;
- создание, редактирование и завершение проектов;
- присоединение к проекту и отказ от участия;
- админ-панель для управления пользователями, навыками и проектами.

## Запуск

Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv venv
pip install -r requirements.txt
```

Создайте файл `.env` на основе `.env_example` и проверьте значения переменных.

Запустите PostgreSQL:

```bash
docker compose up -d
```

Примените миграции и создайте демо-данные:

```bash
python manage.py migrate
python manage.py seed_demo
```

Запустите сервер:

```bash
python manage.py runserver
```

Проект будет доступен по адресу http://127.0.0.1:8000/.
